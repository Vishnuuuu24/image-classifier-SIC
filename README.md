# Image Classification using CNN

A Streamlit web app that classifies images into 1000 ImageNet categories using a
pretrained **MobileNetV3-Large** CNN (PyTorch / torchvision).

## Features
- Upload an image, choose a sample, or take a photo with the camera
- Top-K predictions with confidence bar chart and table
- Inference time display

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
